Connect code to the physical world through experiments, questions, and projects. Begin with the board introduction, then choose a project and follow its lessons in order.

The OLED project is still in progress. More Pico projects are on the way.

Meet the Board

Raspberry Pi Pico WH — What a microcontroller does, what you can build, the kit, an interactive pin guide, and editor resources.

Project 1: The OLED Display

Project guide and roadmap — Check the background knowledge, supplies, and wiring; see the full ten-phase plan.

  1. Meet the OLED — Connect the display, locate pixels, and draw your first text.
  2. Pictures as Data — Represent pictures with bits, bytes, binary, hex, and masks.
  3. Memory Organization — Practice a grid-to-list mapping, then find pixels in pages, bytes, and bits.
  4. The Frame Buffer — Follow drawing into RAM, save a frame, and choose when to send it.
  5. Drawing Graphics — Fit shapes and character cells precisely, compose scenes, and animate frames.

Later phases will explore communication and the controller, then build a small driver.
