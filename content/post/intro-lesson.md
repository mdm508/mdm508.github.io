Scratch and WeScheme are teaching languages that work well for beginners. I have used and enjoyed both, so here are two places to start and a few Scratch games I made.

## WeScheme

Try the [one-hour WeScheme introduction](https://www.bootstrapworld.org/materials/fall2023/en-us/lessons/hoc-wescheme-intro/index.shtml). You need to be able to type in order to follow along.

## Scratch

As long as you can use a mouse, you can use Scratch. Try this [Scratch starter project](https://scratch.mit.edu/projects/781102539) to make a simple snowflake-catching game.
