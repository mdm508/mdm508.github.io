## AP Computer Science A

AP Computer Science A centers on programming and problem-solving in Java. I can help students strengthen the foundations behind their classwork: tracing code, variables and expressions, conditionals, loops, methods, classes and objects, arrays and collections, algorithms, testing, and debugging.

The goal is not to memorize a pattern for one question. We work on recognizing what a problem is asking, choosing a manageable approach, and checking whether the resulting code actually does what the student intended.

## AP Computer Science Principles

AP Computer Science Principles covers a broader view of computing. Support may include programming and algorithms, data, computer systems and networks, abstraction, and explaining the effects of computing. Because schools may use different programming tools or languages, we can work in the environment used by the student’s class.

For Create performance task work, I can clarify course concepts and help a student interpret official requirements, but I will not write or complete submitted work for them. Academic integrity and genuine student understanding come first.

## What we can work on

- Rebuilding a missing prerequisite before it causes more confusion
- Reading and tracing unfamiliar code carefully
- Turning a written problem into smaller programming steps
- Understanding compiler messages and debugging systematically
- Explaining why a solution works, not only getting it to run
- Reviewing class concepts with fresh examples
- Practicing under time constraints without rushing the reasoning
- Developing a realistic study plan before the exam
