Use arrays to organize data and make changes to many values at once. Start with the foundations, then apply the same ideas to pictures.

1. [NumPy: Think in Arrays]({{< relref "/post/numpy-think-in-arrays.md" >}}) — Explore shape, indexing, vectorized operations, Boolean masks, axes, and a small simulation.
2. [Brightening and Averaging Images with NumPy]({{< relref "/post/brightening-and-averaging-images-with-numpy.md" >}}) — Treat pictures as arrays, avoid overflow, clip values, and average images.

These lessons assume basic Python familiarity. Predict the result of each experiment, try it, and use the hints and answers to check your reasoning.
