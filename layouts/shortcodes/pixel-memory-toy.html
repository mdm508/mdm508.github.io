A tiny Lite-Brite: 8 columns × 16 rows
Click a circle to turn it on or off. The outlined vertical group shares one byte. Numbers inside it show bit positions, from 0 at the top to 7 at the bottom.

Click any pixel to follow it into memory.

Page 0 · rows 0–7 · bytes 0–7

Page 1 · rows 8–15 · bytes 8–15

Each box shows its byte index and hex value. The selected byte’s binary digits run from bit 7 on the left to bit 0 on the right.

This toy updates immediately to help you explore the layout. On the real OLED, you still need show() to display your changes.
