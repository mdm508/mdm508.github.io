Deadly Snowflakes: A Scratch Project

May 30, 2025

Scratch and WeScheme are teaching languages that work well for beginners. I have used and enjoyed both, so here are two places to start and a Scratch game I made.

WeScheme

Try the one-hour WeScheme introduction. You need to be able to type in order to follow along.

Scratch

As long as you can use a mouse, you can use Scratch. Try this Scratch starter project to make a simple snowflake-catching game.

A Scratch project I made

Deadly Snowflakes

Here is a remix of the snowflake-catching game where you try to avoid the snowflakes. Control the snowman with the arrow keys.
