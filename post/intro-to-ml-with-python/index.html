Intro to ML With Python

April 19, 2026

An interesting an exciting way to jump right into Python is to go through Jeff Edmond’s fantastic course on Machine learning the full course files contain helpful links to notes and videos. Note that he has more recenet videos available on his youtube-channel.

Setting up

What makes this coures great and fantastic for learning python is that he has created Jupyter notebook labs that let you get hands on practice with ML in Python. You can use google colab as your Python enviorment, meaning you can actually run everything in your browser without setting anything up. Please see this github-repo if you want to download all the notebooks.

To get started, just open up “Lab01.ipynb” and select the “Open in Colab Button” (you will need a gmail account for this to work). Then you should see the notebook open. Go to FILE->SAVE A COPY TO DRIVE, and you are good to go.
